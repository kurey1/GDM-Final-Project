# Project Plan — [Game Title Placeholder]

## 📌 Overview
A 10–11 week development plan for a small, accessible Unity platformer. Each milestone builds toward a final playable build.

---

## 🗂️ Milestones & Deadlines

### **Milestone 1 — Week 1: Setup & Planning**
- Create GitHub repository  
- Add README + initial folder structure  
- Write one‑page GDD  
- Set up project board (Trello/Asana/etc.)  
- Create Unity project  

### **Milestone 2 — Weeks 2–3: Core Movement & Controls**
- Implement player movement + jump  
- Add basic physics  
- Create test scene  
- Commit early prototypes  

### **Milestone 3 — Weeks 3–4: Platforms & Level Elements**
- Add static platforms  
- Add moving platforms  
- Add hazards  
- Begin Level 1 blockout  

### **Milestone 4 — Weeks 4–5: Enemies & Interactions**
- Implement simple enemy AI (walk toward player)  
- Add stomp/attack mechanic  
- Add health system  

### **Milestone 5 — Weeks 5–6: Collectibles & UI**
- Add score pickups  
- Add health pickups  
- Add basic UI (health, score)  

### **Milestone 6 — Weeks 6–8: Level Design**
- Build Levels 1–3 (skill‑building)  
- Playtest + iterate  
- Add polish to visuals  

### **Milestone 7 — Weeks 8–9: Final Challenge Level**
- Build final mastery stage  
- Add transitions + level select  

### **Milestone 8 — Weeks 9–10: Polish & Optimization**
- Improve visuals  
- Add sound effects  
- Fix bugs  
- Prepare final build  

### **Milestone 9 — Week 11: Final Submission**
- Export final build  
- Update README  
- Tag release on GitHub
